CyroTech

Watch your message get encrypted

Real AES-256-GCM, running in your browser with the Web Crypto API. Nothing you type leaves this page.

  1. 1

    Text becomes bytes

    Computers encrypt numbers, not letters. UTF-8 turns each character into 1–4 bytes (numbers from 0 to 255, shown here in hexadecimal). Plain English letters take 1 byte; accents take 2; emoji take 4.

  2. 2

    Password becomes a key

    AES needs exactly 32 random-looking bytes, not a password. PBKDF2 mixes your password with a random salt and repeats a hash many times. The repetition makes every password guess slow for an attacker.

    Salt 16 random bytes, stored with the message

    Key 32 bytes = 256 bits

  3. 3

    A fresh starting point

    The IV (initialisation vector) is 12 random bytes picked for every message. It makes the same message encrypt differently each time, so the key must never be used twice with the same IV.

    IV 12 random bytes

  4. 4

    AES scrambles the bytes

    AES-GCM produces a stream of random-looking bytes from the key and IV and combines it with your message byte by byte. The ciphertext is the same length as your message. GCM also adds a 16-byte tag, a fingerprint that exposes any change.

    ↓ AES-256-GCM

    Ciphertext

    Tag 16 bytes

  5. 5

    Inside AES: 14 rounds

    GCM doesn't feed your text into AES directly. It encrypts a counter block (your IV plus a 4-byte counter), and the output, called the keystream, is combined with your bytes. Here is that block going through all 14 rounds, using your real key. Web Crypto hides these steps, so this step re-runs them in plain JavaScript and checks the result matches.

  6. 6

    Packed into text you can share

    The receiver needs the salt and IV too. They aren't secret, so they're stored in front of the ciphertext. Base64 then turns the bytes into ordinary letters that survive email and chat.

    salt IV ciphertext tag

  7. 7

    Try to break it

    Decryption runs everything backwards. Use a wrong password or change a single bit, and the tag check fails, so nothing is revealed.
